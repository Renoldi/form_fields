# Codegen scripts

One-off scripts that were used to insert or update example snippets in
`example/lib/ui/pages/**/view.dart`. Their changes are already applied.

- They rewrite source files in place. Read a script before you run it, and
  run it from the repository root, because the paths are relative.
- Keep them for reference. Do not run them again unless you need to repeat
  the same edit.
